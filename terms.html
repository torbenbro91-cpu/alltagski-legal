1. Gegenstand

AlltagsKI ist eine Creator-Publish-Oberfläche zum Erstellen einer Vorschau, zum Setzen von Privacy- und Commercial-Optionen und zum Direct Post eigener Videos auf TikTok über die offizielle Login Kit- und Content Posting API (video.publish). Optional kann YouTube angebunden sein.

  • Zugang erfolgt über TikTok OAuth (Login Kit). Freigaben können jederzeit widerrufen werden.

  • Die Software darf nur mit Accounts genutzt werden, die dem Nutzer gehören oder für die eine ausdrückliche Berechtigung vorliegt.

  • Kein Upload fremder oder rechtswidriger Inhalte.
